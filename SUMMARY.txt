                         PROCHAINES ÉTAPES
═══════════════════════════════════════════════════════════════════════

1. ✅ Vérifier l'installation
   $ ./manage-mcp.sh status

2. 🔄 Redémarrer OpenWork
   → Activer les serveurs MCP
   → Skills automatiquement disponibles

3. 📖 Lire la documentation
   → Commencer par : SKILLS_GUIDE.md
   → Puis : QUICKSTART.md
   → Détails : swiss-case-law-research/SKILL.md et swiss-legal-commentary/SKILL.md

4. 🧪 Tester les capacités
   → "Cherche des décisions sur la protection des données"
   → "Explique l'article 328 du Code des Obligations"
   → "Quelle est la jurisprudence récente sur le télétravail ?"

5. 🔧 Maintenance régulière
   $ ./manage-mcp.sh update-all
