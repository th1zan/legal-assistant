# Sources doctrinales suisses

## Types de publications doctrinales

| Type | Description | Exemple |
|------|-------------|---------|
| **Traités et manuels** | Ouvrages généraux couvrant un domaine | Tercier/Pichonnaz, *Le droit des obligations* |
| **Grands commentaires** | Commentaire article par article exhaustif | Commentaire romand CC I, Commentaire bâlois |
| **Petits commentaires** | Commentaire synthétique | *Handkommentar*, *Kurzkommentar* |
| **Monographies** | Études approfondies sur un sujet précis | Thèses de doctorat, habilitations |
| **Articles de revues** | Publications dans des périodiques juridiques | SJ, RSJ, PJA, RDAF, RDS |
| **Mélanges** | Ouvrages collectifs en l'honneur d'un auteur | *Mélanges en l'honneur de X* |

## Catalogues de bibliothèques

### swisscovery (anciennement RERO, Nebis, Helveticat)
- **URL** : swisscovery.slsp.ch
- Catalogue unifié des bibliothèques suisses (universités, BN, hautes écoles)
- Regroupe depuis 2020 les anciens catalogues RERO, Nebis, Helveticat
- Recherche par auteur, titre, sujet, ISBN
- Intégration avec Google Scholar (lien « Trouver dans swisscovery »)
- Couvre les monographies, thèses, et partiellement les articles

### Alexandria
- **URL** : alexandria.ch
- Bibliothèques de l'administration fédérale
- **Excellent pour les articles de revues** (indexation fine des périodiques juridiques)
- Indexation par descripteurs thématiques

### Google Scholar
- scholar.google.ch
- Recherche d'articles académiques
- Intégration swisscovery : configurer les liens vers la bibliothèque
- Fonctions utiles :
  - **« Cité par »** : trouver les articles citant une publication
  - **Profils d'auteurs** : voir toutes les publications d'un juriste

## Recherche de doctrine dans Swisslex

> ⚠️ **Accès payant** : Swisslex nécessite un abonnement (disponible via universités/cabinets d'avocats)

Swisslex indexe de nombreuses **revues juridiques suisses** :
- Résumés d'articles
- Liens vers les textes intégraux (pour les abonnés)
- Recherche par mots-clés, auteur, revue, date

## Stratégie de recherche doctrinale

1. **Identifier le sujet** → mots-clés, articles de loi concernés
2. **Chercher les commentaires** de la loi applicable (Commentaire romand, Commentaire bâlois)
3. **Chercher dans les catalogues** (swisscovery, Alexandria) par sujet et auteur
4. **Chercher dans Swisslex** pour les articles de revues récents (⚠️ payant)
5. **Google Scholar** pour élargir aux publications académiques
6. **Suivre les citations** : chaque source doctrinale renvoie à d'autres sources

Pour les conventions de citation → skill `citation-juridique-suisse`
