# Veille juridique suisse

## Principe

La veille juridique permet de suivre **en continu** l'évolution du droit sans refaire manuellement des recherches. Elle combine outils automatiques et sources manuelles.

## Outils de veille automatique

### Alertes par e-mail

| Outil | Type | Configuration |
|-------|------|--------------|
| **Google Alerts** | Gratuit | google.com/alerts — saisir les termes, choisir la fréquence |
| **Swisslex** | ⚠️ Payant | Sauvegarder une recherche → recevoir les nouveaux résultats par e-mail |
| **ChangeDetection** | Gratuit | changedetection.com — surveiller les modifications d'une page web |

### Flux RSS

Certaines sources proposent des flux RSS pour suivre les mises à jour :
- Nouveaux arrêts du TF (bger.ch)
- Nouvelles publications au RO/RS (fedlex.admin.ch)
- Actualités du Parlement (parlement.ch)

> **Astuce** : utiliser un agrégateur RSS (Feedly, Inoreader) pour centraliser les flux.

## Newsletters juridiques

| Newsletter | Éditeur | Fréquence | Contenu |
|------------|---------|-----------|---------|
| **Jusletter** | Weblaw | Hebdomadaire | Articles, résumés d'arrêts, actualités |
| **News Service du Parlement** | parlement.ch | Selon sessions | Objets parlementaires, votes, communiqués |
| **Catalogues Schulthess/Stämpfli** | Éditeurs | Mensuel | Nouvelles publications doctrinales |
| **Circulaires des offices fédéraux** | admin.ch | Variable | Directives, pratiques administratives |

## Veille législative

### Suivi des modifications du RS
- **Fedlex** (fedlex.admin.ch) : liste des actes récemment modifiés, historique des versions
- Swisslex (⚠️ payant) : comparer les versions d'un texte législatif dans le temps

### Suivi des projets de loi
- **parlement.ch** : base de données des objets parlementaires
  - Filtrer par état (« en cours », « terminé »)
  - S'abonner aux notifications d'un objet spécifique
- **fedlex.admin.ch** : procédures de consultation en cours

### Suivi des ordonnances
- Les ordonnances sont souvent modifiées sans débat public
- Surveiller le RO hebdomadaire via RSS ou consultation manuelle

## Veille jurisprudentielle

### Nouveaux arrêts du TF
- **bger.ch** : publication des arrêts dans les jours suivant le prononcé
- **Swisslex** (⚠️ payant) : alertes sur les nouveaux arrêts dans un domaine
- **Jusletter** : résumés commentés des arrêts importants

### Jurisprudence cantonale
- Sites des tribunaux cantonaux
- Swisslex (⚠️ payant — pour les cantons indexés)
- Revues cantonales spécialisées

## Veille doctrinale

- **Google Scholar** : créer des alertes par sujet ou par auteur
- **swisscovery** (swisscovery.slsp.ch) : suivre les nouvelles acquisitions par sujet
- **Revues** : abonnement aux tables des matières
- **Swisslex** (⚠️ payant) : alertes sur les nouveaux articles indexés

## Bonnes pratiques

1. **Définir le périmètre** : quels domaines du droit surveiller
2. **Combiner les sources** : gratuit (Google Alerts, RSS) + payant (Swisslex ⚠️)
3. **Centraliser** : utiliser un agrégateur pour ne rien manquer
4. **Revoir périodiquement** : ajuster les alertes selon l'évolution des besoins
5. **Archiver** : conserver les résultats pertinents de manière organisée
