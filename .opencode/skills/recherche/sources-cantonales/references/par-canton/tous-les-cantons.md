## Portail unifié

### Lexfind
- **URL** : https://www.lexfind.ch/
- **Description** : Portail de recherche fédéré permettant de chercher simultanément dans tous les recueils systématiques cantonaux et fédéral
- **Fonctionnalités** :
  - Recherche par numéro systématique
  - Recherche par titre
  - Recherche plein texte
  - Filtrage par canton/confédération
  - Filtrage par type d'acte (constitution, loi, ordonnance, etc.)
